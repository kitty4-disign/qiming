# K12 AI Classroom — Five-Minute Competition Demo Script

> 面向评委的五分钟可复现演示脚本。每段包含点击路径、预期可见结果、备用截图/录屏，以及一句对应评分标准的映射。演示前请先完成 [docs/k12-knowledge-base-setup.md](k12-knowledge-base-setup.md) 中的知识库建库与索引，并通过 `deeptutor start` 启动后端与前端（默认 `http://127.0.0.1:3782`）。

## 演示前置条件

- DeepTutor 已启动，浏览器可访问 `http://127.0.0.1:3782`。
- 四个 K12 知识库（`k12-ai-primary-lower`、`k12-ai-primary-upper`、`k12-ai-middle`、`k12-ai-high`）已在 Knowledge Center 中创建并索引（可通过 `GET /api/v1/knowledge/list` 验证）。
- 已配置可用的 LLM 模型（Settings → Models）。
- 演示账号为当前登录用户，画像未初始化（首次进入 `/education` 会进入 onboarding）。

## 时间分配

```text
00:00-00:40 选择小学高年级、五年级和教材
00:40-01:40 展示K12导师的生活化讲解和主动提问
01:40-02:30 启动动画讲解
02:30-03:20 完成三题趣味测验并查看即时反馈
03:20-04:10 查看掌握度和下一知识点推荐
04:10-05:00 切换高中画像，展示Python编程任务与难度变化
```

---

### 00:00-00:40 选择小学高年级、五年级和教材

**点击路径**

1. 浏览器打开 `http://127.0.0.1:3782/education`。
2. 在弹出的学生画像表单中点击「小学高年级」分段按钮。
3. 在「年级」下拉框选择「五年级」。
4. 确认「教材」自动锁定为 `AI探索与创造`（`k12-ai-primary-upper`），不可跨学段选择。
5. 兴趣填入「机器人、绘画」，学习目标填入「理解图像识别是怎样学习的」。
6. 点击「保存学习画像」。

**预期可见结果**

- 保存后页面切换到 K12 学习工作台，顶部显示学生姓名、五年级、所选教材。
- 课程概览显示「图像识别大冒险」标题与摘要。
- 若对应知识库未就绪，页面顶部出现「教材知识库尚未就绪」警告条（不阻塞功能）。

**备用**：截图 `education-onboarding.png`，录屏 `onboarding.mp4`。

**评分映射**：完成学生画像建模与学段化教材路由，体现「因材施教」的个性化起点。

---

### 00:40-01:40 展示K12导师的生活化讲解和主动提问

**点击路径**

1. 在学习工作台「开始课堂」动作卡片上点击「打开」。
2. 页面跳转到 `/home`，能力按钮显示为 `K12 AI Tutor`。
3. 观察输入框：草稿已预填包含「图像识别大冒险」的开场白，但**未自动发送**。
4. 点击发送，观察 K12 导师的回复。

**预期可见结果**

- `/home` 路由生效，能力标签为 `K12 AI Tutor`。
- 草稿包含课程主题「图像识别大冒险」，需要用户主动点击发送，证明不会自动消耗额度。
- 导师回复使用生活化比喻（如像素、拼图），每轮以一个简单问题确认理解，符合小学高年级策略。
- 回复末尾不索取任何私人联系方式、住址、密码等信息（安全规则生效）。

**备用**：截图 `k12-dialogue.png`，录屏 `dialogue.mp4`。

**评分映射**：学段自适应提示词与掌握式对话，体现「年龄适配 + 主动提问」的教学能力。

### 01:40-02:30 启动动画讲解

**点击路径**

1. 返回 `/education`。
2. 在「动画讲解」动作卡片上点击「打开」。
3. 页面跳转到 `/home`，能力切换为 `visualize`，渲染模式为 HTML。
4. 观察草稿预填主题，点击发送生成动画讲解。

**预期可见结果**

- 能力标签切换为可视化能力，复用既有 `visualize` 管线。
- 生成带标注步骤的 HTML 交互讲解，无自动播放音频。
- 讲解内容围绕当前课程主题（图像特征 / 训练集）。

> **M0 基线状态（待 M2 修复）：** 当前 `education-launch-adapter.ts` 中动画的 `style_hint` 为静态英文 `"K12 interactive explanation with labeled steps and noautoplay audio"`，未按学段（小学/初中/高中）生成差异化样式提示。M2 将改为由学段策略生成 `style_hint`。

**备用**：截图 `k12-animation.png`，录屏 `animation.mp4`。

**评分映射**：多模态动画讲解复用既有能力，体现「多模态教学」。

---

### 02:30-03:20 完成三题趣味测验并查看即时反馈

**点击路径**

1. 返回 `/education`。
2. 在「趣味测验」动作卡片上点击「打开」。
3. 页面跳转到 `/home`，能力切换为 `deep_question`（测验）。
4. 确认配置：题目数量为 3，难度为 `auto`，题型为「选择题 + 概念题」。
5. 点击发送，完成三题并提交。

**预期可见结果**

- 能力标签为测验，题目数量为 3。
- 提交后出现即时反馈与正确答案解析，错题进入错题本。
- 题目围绕图像识别核心知识点（像素、特征、训练测试集）。

> **M0 基线状态（待 M1 修复）：** 当前 `education-launch-adapter.ts` 将 quiz 路由到独立的 `deep_question` 能力，未接入课程的稳定 `mastery_path_id`。测验结果不会写回该课程的掌握度路径，个性化闭环在此断开。M1 将把 K12 测验映射到 `k12_tutor`（`activity_mode="quiz"`），通过 `mastery_status` → `mastery_quiz` → `ask_user` → `mastery_grade` 流程真正更新掌握度。

**备用**：截图 `k12-quiz.png`，录屏 `quiz.mp4`。

**评分映射**：自动测验与即时反馈，体现「形成性评价」。

---

### 03:20-04:10 查看掌握度和下一知识点推荐

**点击路径**

1. 返回 `/education`。
2. 查看「知识地图 / 掌握度」区域。

**预期可见结果**

- 掌握度面板显示已掌握、学习中、新知识点的计数（复用 `fetchMasteryMap`）。
- 使用稳定的学习路径 ID `edu_k12_ai_primary_upper_image_recognition`。
- 推荐下一知识点（如「训练集与测试集」）。

> **M0 基线状态（待 M1 修复）：** `MasterySummary.tsx` 当前仅展示「已掌握 / 学习中 / 新知识」三项计数，**未展示**演示文档声称的「下一知识点推荐」。M1 将新增 `RecommendedNextStep.tsx` 组件，调用确定性推荐器（`recommender.py`）展示具体知识点名称、推荐活动、推荐理由和证据，并通过 `LearningTimeline.tsx` 展示最近学习事件。

**备用**：截图 `k12-mastery.png`，录屏 `mastery.mp4`。

**评分映射**：掌握式学习闭环与下一知识点推荐，体现「个性化进度追踪」。

---

### 04:10-05:00 切换高中画像，展示Python编程任务与难度变化

**点击路径**

1. 点击工作台顶部「编辑画像」图标按钮。
2. 将学段改为「高中」，年级改为「十一年级」，教材改为 `Python人工智能项目`（`k12-ai-high`）。
3. 保存画像。
4. 在「编程实践」动作卡片上点击「打开」。
5. 页面跳转到 `/home`，能力为 `K12 AI Tutor`，工具仅启用 `code_execution`。

**预期可见结果**

- 高中画像下课程切换为「从零实现图像分类器」。
- 编程实践仅启用代码执行工具，草稿提示「先给我一个可运行的代码框架」。
- 导师策略切换为准确术语、算法复杂度、可运行 Python、误差与局限分析，与小学高年级明显不同。

**备用**：截图 `k12-high-coding.png`，录屏 `high-coding.mp4`。

**评分映射**：同一系统跨学段适配，高中阶段提供可运行代码与工程权衡，体现「分层难度 + 编程实践」。
